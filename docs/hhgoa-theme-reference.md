# HH Goa Theme Reference — Applied Design Direction

The supplied HH Goa homepage uses a **tropical editorial** visual language rather than a conventional software-dashboard aesthetic. The app redesign will borrow the high-level language, not copy its artwork or layout.

| Reference cue | App translation |
|---|---|
| Deep emerald tropical field | Dark palm-green application background with subtle paper/grain texture |
| High-contrast yellow display typography | Warm yellow display headings and primary action emphasis |
| Bright pink accents | Sparse accent for warnings, active language selection, and important status moments |
| Condensed editorial title style | Serif display typography for hierarchy; monospaced metadata for system facts |
| Playful but precise framing | Squared/offset card corners, thin yellow rules, and intentional outlined controls |
| “Builder” energy | Technical facts remain clear: index state, retrieval source, guardrails, and latency are still prominent |

The design preserves accessibility: body text remains high contrast, destructive states continue to use a distinct accessible red, and interactive controls retain focus indicators.
